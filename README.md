# 🚀 Nuraiyan (নূরাইয়ান) - আধুনিক সোশ্যাল নেটওয়ার্ক প্ল্যাটফর্ম
### Facebook + Instagram + Messenger + Snapchat এর সমস্ত ফিচারের ফুল কম্বো

এই প্ল্যাটফর্মটি অত্যন্ত আধুনিক, হাইপার-স্কেলেবল এবং সর্বোচ্চ নিরাপত্তাসম্পন্ন আর্কিটেকচার দিয়ে তৈরি করা হয়েছে।

---

## 🌟 প্রধান প্রধান ফিচারসমূহ

1. **নিউজ ফিড ও পোস্ট সিস্টেম (Facebook Style)**:
   - টেক্সট, ছবি ও ভিডিও সমৃদ্ধ পোস্ট তৈরি।
   - ৬ ধরণের রিয়্যাকশন (👍 Like, ❤️ Love, 😂 Haha, 😮 Wow, 😢 Sad, 😡 Angry)।
   - নেস্টেড কমেন্ট এবং রিয়েল-টাইম রিপ্লাই।
   - পোস্ট শেয়ার এবং বুকমার্ক/সেভ ফিচার।
   - প্রাইভেসি নিয়ন্ত্রণ (পাবলিক, ফ্রেন্ডস, শুধুমাত্র আমি)।

2. **২৪ ঘণ্টার স্টোরিজ (Snapchat ও Instagram Style)**:
   - ছবি ও ভিডিও দিয়ে স্টোরি আপলোড যা ২৪ ঘণ্টা পর স্বয়ংক্রিয়ভাবে মুছে যাবে (`expiresAt`)।
   - ইনস্টাগ্রাম স্টাইলের রঙধনু গ্র্যাডিয়েন্ট স্টোরি রিং।
   - ৫ সেকেন্ডের প্রোগ্রেস বারসহ ফুলস্ক্রিন স্টোরি ভিউয়ার ও সরাসরি রিপ্লাই।

3. **মেসেঞ্জার (Messenger Style)**:
   - ১-অন-১ এবং গ্রুপ চ্যাট।
   - ইনস্ট্যান্ট টাইপিং ইন্ডিকেটর ("Typing...") ও সিন/রিড রিসিপ্ট।
   - **Snapchat Vanish Mode (ভ্যানিশ মোড)**: চ্যাট দেখার পর স্বয়ংক্রিয়ভাবে উধাও হয়ে যাওয়া বার্তা।
   - ছবি, ভয়েস মেসেজ ও মিডিয়া শেয়ারিং।

4. **অডিও ও ভিডিও কলিং (WebRTC Audio/Video Call)**:
   - ব্রাউজার-টু-ব্রাউজার আল্ট্রা লো-ল্যাটেন্সি কলিং (পিয়ার-টু-পিয়ার)।
   - ক্যামেরা অন/অফ, মাইক্রোফোন মিউট/আনমিউট ও পিআইপি (Picture-in-Picture) স্ক্রিন।
   - এন্ড-টু-এন্ড এনক্রিপ্টেড (E2EE)।

5. **লাইভ স্ট্রিমিং (Facebook & TikTok Live Style)**:
   - ক্যামেরা দিয়ে সরাসরি লাইভ ব্রডকাস্টিং।
   - ভাসমান লাভ ও রিঅ্যাকশন অ্যানিমেশন (Floating Hearts Animation)।
   - রিয়েল-টাইম কমেন্ট স্ট্রিম ও লাইভ ভিউয়ার কাউন্টার।

6. **সার্চ ও এক্সপ্লোর**:
   - রিয়েল-টাইম ইউজার, পোস্ট ও ট্রেন্ডিং হ্যাশট্যাগ অনুসন্ধান।

## 🛠 টেকনোলজি স্ট্যাক (Tech Stack)

| লেয়ার | প্রযুক্তি | ভূমিকা |
| :--- | :--- | :--- |
| **Frontend** | **Next.js (React Framework)** + TypeScript | সার্ভার-সাইড রেন্ডারিং, App Router, আল্ট্রা ফাস্ট UI |
| **Styling** | **Tailwind CSS** + Lucide Icons | রেসপনসিভ ও আধুনিক ডিজাইন |

| **State** | **Zustand** | লাইটওয়েট গ্লোবাল স্টেট ম্যানেজমেন্ট |
| **Backend** | **Node.js (Express / NestJS)** + TypeScript | এন্টারপ্রাইজ গ্রেড মডুলার ব্যাকএন্ড |
| **Database** | **PostgreSQL** + Prisma ORM | রিলেশনাল ডাটা (ইউজার, পোস্ট, রিঅ্যাকশন, ফ্রেন্ডস) |
| **Cache/TTL** | **Redis** | ২৪ ঘণ্টার স্টোরি ট্র্যাকিং ও পাব/সাব |
| **Security** | **Argon2 + JWT + Helmet + RateLimit** | মিলিটারি-গ্রেড পাসওয়ার্ড হ্যাশিং ও প্রটেকশন |

## 🔒 সর্বোচ্চ নিরাপত্তা ব্যবস্থা (Security Standards)

- **Argon2id**: পাসওয়ার্ড সংরক্ষণের জন্য বর্তমান বিশ্বের সবচেয়ে নিরাপদ এলগরিদম।
- **HttpOnly & Secure Cookies**: XSS আক্রমণ থেকে টোকেন চুরি ঠেকাতে রিফ্রেশ টোকেন সিকিউর কুকিতে রাখা হয়।
- **Rate Limiting**: ব্রুট-ফোর্স অ্যাটাক ও DDoS রোধ করতে এক্সপ্রেস রেট লিমিটিং সংযুক্ত।
- **Helmet.js**: সমস্ত ক্ষতিকর HTTP হেডার ব্লক করা।
- **Zod Data Validation**: প্রতিটি ইনপুট যাচাই বাছাই করা যাতে SQL Injection বা Malicious Payload ঢুকতে না পারে।

## 🚀 লোকাল মেশিনে রান করার নির্দেশিকা (Mac / Windows)

### 🍏 Mac (Apple Silicon M-Series) কুইক স্টার্ট:

১. **প্রথমবার Mac এ সেটআপ (Windows ফাইল ও ক্যাশ ক্লিন করে নেটিভ ইন্সটল):**
```bash
./setup-mac.sh
# অথবা: npm run setup:mac
```

২. **এক কমান্ডে ব্যাকএন্ড + ফ্রন্টএন্ড চালানো:**
```bash
./start-dev.sh
# অথবা: npm run dev
```

---

### 🖥️ ম্যানুয়াল সেটআপ পদ্ধতি (Mac / Linux / Windows):

#### ১. ডেটাবেস চালু করা (Docker দিয়ে):
```bash
docker compose up -d
```
এটি আপনার কম্পিউটারে স্বয়ংক্রিয়ভাবে **PostgreSQL (Port 5432)** এবং **Redis (Port 6379)** চালু করে দেবে।

#### ২. ব্যাকএন্ড সেটআপ ও চালু:
```bash
cd backend
npm install
npx prisma generate
npm run dev
```
ব্যাকএন্ড চালু হবে: `http://localhost:5001` এ।

#### ৩. ফ্রন্টএন্ড সেটআপ ও চালু:
```bash
cd frontend
npm install
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

## 🌐 হোস্টিং এবং ডোমেইন সেটআপ গাইড

### ১. ফ্রন্টএন্ড হোস্টিং (Vercel)
1. GitHub এ ফ্রন্টএন্ড কোড পুশ করুন।
2. [Vercel.com](https://vercel.com) এ লগইন করে `Import Repository` দিয়ে `frontend` ফোল্ডারটি সিলেক্ট করুন।
3. `NEXT_PUBLIC_API_URL` হিসেবে আপনার ব্যাকএন্ডের ডোমেইন লিংক দিন।
4. `Deploy` বাটনে ক্লিক করলেই সাইট লাইভ হয়ে যাবে!

### ২. ব্যাকএন্ড এবং ডেটাবেস হোস্টিং (Railway)
1. [Railway.app](https://railway.app) এ লগইন করুন।
2. `New Project` -> `Provision PostgreSQL` এবং `Provision Redis` সিলেক্ট করুন।
3. আপনার গিটহাব রিপোজিটরির `backend` ডিরেক্টরি কানেক্ট করুন।
4. Railway এর ড্যাশবোর্ডে `DATABASE_URL`, `JWT_ACCESS_SECRET` এনভায়রনমেন্ট ভেরিয়েবল সেট করে ডিপ্লয় দিন।

### ৩. Namecheap ডোমেইন কনফিগারেশন
1. Namecheap ড্যাশবোর্ডে গিয়ে আপনার কেনা ডোমেইনের পাশে **Manage** এ ক্লিক করুন।
2. **Advanced DNS** ট্যাবে যান:
   - **Frontend (Vercel)** এর জন্য:
     - `Type: CNAME Record`, `Host: @`, `Value: cname.vercel-dns.com`
     - `Type: CNAME Record`, `Host: www`, `Value: cname.vercel-dns.com`
   - **Backend API (Railway)** এর জন্য:
     - সাবডোমেন তৈরি করুন যেমন: `api.yourdomain.com`
     - `Type: CNAME Record`, `Host: api`, `Value: your-backend.up.railway.app`
3. SSL সার্টিফিকেট স্বয়ংক্রিয়ভাবে Vercel ও Railway বিনামূল্যে (Let's Encrypt) ইস্যু করে দেবে।
